BUSINESS PROCESS → AUTOMATED SYSTEM

From unstructured inquiry to an actionable lead.

The workflow separates language interpretation from business decisions. OpenAI handles extraction and reply drafting, while validation, duplicate prevention, scoring, HTTP responses, routing, and error handling remain explicit and inspectable.

Model-assisted processing

Interpretation + communication
Structured extraction

GPT-5 Mini converts free-form inquiries into project type, budget, currency, timeline, requirements, and urgency.

Personalized response

A second model step drafts a concise client reply using the structured lead data without inventing pricing, availability, or delivery commitments.

Deterministic qualification

Lead quality is calculated with explicit JavaScript rules so the result stays predictable and explainable.

03

Explainable scoring

0–100 deterministic model
CONTACTComplete contact information · +10Name, email, and inquiry message are present.
PROJECTClear project type · +25A specific project category was extracted.
BUDGETAmount + currency · up to +25Rewards provided commercial context without assuming budget fit.
TIMELINE + DETAILTimeline + requirements · up to +40Measures inquiry completeness and clarity.

Classification: Hot 80–100 · Warm 50–79 · Cold 0–49. This is a completeness / intent score, not a prediction of client value.

04

Production-style safeguards

Validation · cost control · observability
VALIDATIONReject bad input early

Missing fields and malformed email addresses are logged and return HTTP 400 before downstream processing.

DEDUPLICATIONStop repeats before processing

A normalized email + inquiry key blocks duplicate model calls, rows, replies, and internal alerts.

ERROR HANDLINGSeparate failure workflow

Unhandled production failures trigger an internal alert with the failed node, error message, execution ID, timestamp, and execution link.
