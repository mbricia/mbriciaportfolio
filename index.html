03

Explainable scoring

0–100 deterministic model
CONTACTComplete contact information · +10Name, email, and inquiry message are present.
PROJECTClear project type · +25A specific project category was extracted.
BUDGETAmount + currency · up to +25Rewards provided commercial context without assuming budget fit.
TIMELINE + DETAILTimeline + requirements · up to +40Measures inquiry completeness and clarity.

Classification: Hot 80–100 · Warm 50–79 · Cold 0–49. This is a completeness / intent score, not a prediction of client value.

ERROR HANDLINGSeparate failure workflow

Unhandled production failures trigger an internal alert with the failed node, error message, execution ID, timestamp, and execution link.

Inventory & Low-Stock
Business Automation

A scheduled n8n workflow that turns a familiar inventory spreadsheet into an active monitoring system. It checks stock levels automatically, identifies items at or below reorder thresholds, creates a consolidated reorder list, and sends separate HTML alerts and management summaries.

ROLEWorkflow Designer / Builder
ORCHESTRATIONn8n · Schedule Trigger
DATA SOURCEGoogle Sheets
OUTPUTGmail · HTML Reports

SPREADSHEET → ACTIVE MONITORING

Keep stock updates simple. Automate the checking.

Staff continue updating current stock in Google Sheets. The automation handles the repetitive monitoring work in the background: threshold comparison, low-stock filtering, consolidation, inventory-health metrics, and scheduled email reporting.

02

Deterministic business rules

No runtime AI dependency
LOW STOCKcurrent_stock ≤ reorder_levelEvery row is evaluated against its own configurable threshold.
ALERT DESIGNMany rows → one reorder emailLow-stock records are aggregated before Gmail so the business receives one actionable alert instead of one message per item.
HEALTH METRICSTotal · Low Stock · Healthy StockThe reporting branch calculates an at-a-glance inventory status from the complete dataset.
03

Two outputs, two purposes

Action + visibility
Low-stock reorder alert

Sent only when the TRUE branch contains items. Includes current quantity, recommended reorder quantity, unit, and supplier in an HTML table.

Daily inventory summary

Runs from the full inventory dataset and reports total items, low-stock count, healthy-stock count, and the items currently below threshold.

Independent reporting branch

The summary still completes even when no items require reordering.
